# Skyplane — Cloud Run

A mobile-first monochrome 2D plane game inspired by the supplied image.

## Publish with GitHub Pages
1. Create a public repository named `skyplane`.
2. Upload all files in this folder to the repository root (not the ZIP itself).
3. Go to Settings → Pages.
4. Select **Deploy from a branch**, branch `main`, folder `/(root)`, then Save.
5. Open the URL shown on Pages settings after deployment completes.
6. On Android Chrome, open the URL → ⋮ → Install app / Add to Home screen.

## Controls
Touch the left or right side to steer. Touch near the top of the screen to climb; release or touch lower down to descend. Avoid clouds. Tap pause to pause. Best score is saved locally in this browser.
